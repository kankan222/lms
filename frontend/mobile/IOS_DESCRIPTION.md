# Description (4000 char)
Kalong Kapili LMS is an all-in-one school management app designed for administrators, teachers, and staff.

The app helps your institution run daily academic and administrative work from one place. Instead of maintaining separate registers and manual sheets, teams can use a single mobile system to manage student records, teacher workflows, attendance, fees, exams, and reporting.

Core capabilities:
- Student management with profile and enrollment details
- Teacher management with attendance logs
- Class and section operations
- Fee and payment tracking
- Exam and marks workflows
- Report access and review support
- Internal communication and messaging tools

How it helps your team:
- Reduces repetitive manual data entry
- Improves data consistency across modules
- Makes updates and review faster for staff
- Supports better visibility into daily school operations

Kalong Kapili LMS is built for practical school use, with a clear interface and role-based workflows that support administration and academics together.
